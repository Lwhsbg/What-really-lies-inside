# What really lies inside

Demo: https://lwhsbg.itch.io/what-really-lies-inside 

## What It Is

It is a short horror and a mystery visual novel made using renpy inspired by all the choice games in itch.io. You wind up in a mansion due to strange circumstances in the night and then trapped, and the different choices that you make manipulates the ending you will have.

## Why I Made It
I just wanted to try some type of new system where you cannot redo the choice once it has been made as my games felt like it was the same trope every time, so i experimented that in this game and it somehow suceeded. Also i wanted to make the game look like its being played using first person mode.
